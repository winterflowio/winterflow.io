3.5.0 - 2026-09-28

[!WARNING] Breaking change: Plex and Jellyfin library API endpoints (#3321)

GET /settings/plex/library and GET /settings/jellyfin/library no longer accept the sync or enable query parameters, and reading libraries no longer changes their enabled state. If you have scripts, integrations, or third-party clients that use these to sync or toggle libraries, switch to:

  • Sync libraries: POST /settings/plex/library/sync and POST /settings/jellyfin/library/sync
  • Enable or disable a library: PUT /settings/plex/library/{libraryId} and PUT /settings/jellyfin/library/{libraryId}

The web UI already uses the new endpoints, so only direct API consumers are affected. Because of that limited scope, this ships in a minor release rather than a major one.
