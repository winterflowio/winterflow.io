About Versions (28)

Wine Cellar is a self-hosted wine management app built with Django for wine enthusiasts to track wines, store tasting notes, rate bottles, and manage inventory. It supports multi-user hosting, barcode scanning to add or remove bottles, food pairing notes, and email reminders for wines nearing their drink-by date.

Wine Cellar Docker Compose example

Self-host Wine Cellar on your own server, homelab, or VPS starting from this Docker Compose example. It runs Wine Cellar in Docker containers using the official ghcr.io/the-broke-sommeliers/wine-cellar-web:latest, postgres:16, redis:8-alpine, caddy:2, ghcr.io/the-broke-sommeliers/wine-cellar-web:latest, ghcr.io/the-broke-sommeliers/wine-cellar-web:latest images, with persistent volumes and automatic restarts preconfigured. Review the environment variables and adjust them to your setup, save the file as compose.yml (or docker-compose.yml), and start the stack with docker compose up -d. 

services:

    command: gunicorn wine_cellar.conf.wsgi:application --bind 0.0.0.0:8000 --worker-class gthread --threads 4 --workers 2

      DJANGO_SITE_URL: "https://example.org"

      DJANGO_CSP_FORM_ACTION_EXTRA: ""

      # Name of the PostgreSQL database.

      # PostgreSQL password.
      SQL_PASSWORD: "changeme"
      SQL_HOST: "db"

      # Username of the initial admin account created on first start.

    environment:
      DJANGO_DEBUG: "False"

Extra files

The Docker Compose configuration above bind-mounts the following file. Save it next to your compose.yml, keeping the same relative path.

Caddyfile

:80 {

@files {
	path /static/* /media/*
}
handle @files {
		file_server
	}

handle {
	@health path /health
    respond @health "Not Found" 404
	reverse_proxy web:8000
}
}
